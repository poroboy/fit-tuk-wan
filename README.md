# ฟิตทุกวัน

เว็บแอป (PWA) ออกกำลังกายส่วนตัว สำหรับเล่นที่ห้องด้วยดัมเบล 4.5 กก. และบอร์ดวิดพื้น

- ตารางเล่น 5 ช่วง + สัปดาห์เบา + ปุ่ม "อยู่ช่วงเดิมต่อ"
- แอนิเมชันตัวการ์ตูนสาธิตทั้ง 18 ท่า (วาดด้วยโค้ด อยู่ใน `js/figure.js`) โดยบอร์ดวิดพื้นใช้สีตามที่ตั้งค่า
- โหมดนำเล่น ติ๊กทีละเซ็ต จับเวลาพัก/แพลงก์ มีเสียงและสั่น เล่นชดเชยได้
- สตรีคไฟ 🔥 สถิติ กราฟวิดพื้น กราฟ volume รายสัปดาห์
- นับแคล + โปรตีน: ให้ AI (Google Gemini) คำนวณจากชื่อเมนูหรือรูป มีเมนูของฉัน และกรอกเองได้ ใช้ Gemini API key ของผู้ใช้เอง ซึ่ง key เก็บในเครื่องเท่านั้น และแอปจะเลือกโมเดล Flash รุ่นใหม่สุดที่ใช้ได้ให้อัตโนมัติ
- ติดตามน้ำหนัก (มีเส้นเฉลี่ย 7 วัน), รอบตัว, รูปก่อน-หลัง (เลื่อนเทียบได้) และคำแนะนำตามข้อมูล
- แจ้งเตือนในแอป, Periodic Background Sync (Chrome) และปุ่มเพิ่มนัดลง Google Calendar
- ข้อมูลอยู่ในเครื่อง (IndexedDB) สำรองด้วย Export/Import JSON ได้

## รันบนคอม

```powershell
python -m http.server 5173
```

แล้วเปิด http://localhost:5173

## ใช้บนมือถือ Android

ต้องเปิดผ่าน HTTPS เช่น GitHub Pages แล้วใน Chrome ให้เลือก ⋮ → **ติดตั้งแอป / เพิ่มไปยังหน้าจอหลัก**

## หมายเหตุ

- ไม่มี build step เป็น HTML/CSS/JS ล้วน
- ถ้าแก้ไฟล์ ให้เปลี่ยน `VERSION` ใน `sw.js` เพื่อให้มือถือโหลดเวอร์ชันใหม่
- สร้างไอคอนใหม่ได้ด้วยคำสั่ง `node tools/make-icons.mjs`
